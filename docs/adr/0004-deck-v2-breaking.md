# ADR-0004 deck 契约升 v2，放弃 v1 兼容

- 状态：已接受（2026-11-18）

## 背景

指挥台目前读 v1 快照（工作区文件 + workspaceFiles 通道）。看板加了状态、认领者、优先级之后，v1 结构无法表达这些信息。

## 决策

deck 升到 v2：cards 带 status / assignee / priority / rev，records 只投影摘要。不保留 v1 适配层。旧会话打开指挥台显示占位提示，数据仍在。

## 后果
正面：前端只按一种契约写，代码不必长期分叉；新信息一次到位。
负面：旧会话的指挥台退化（用户已接受）；旧快照刷不出看板需重派发。
被放弃的方案：保留最小 v1→v2 适配层（永久兼容代码）；后台批量重写旧快照（要扫工作区并改盘上文件）。
